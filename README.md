# OECD-EULNS

Code and report assets for the OECD/EU Legal Needs Survey country reports.

The current R pipeline is configured for Hungary, Italy, Malta, and Poland. It builds the analysis tables, visualization assets, and main-indicator workbooks used in the country report workflow.

## Prerequisites

- R 4.6.0, as recorded in `renv.lock`
- A POSIX-compatible terminal: macOS, Linux, or WSL on Windows
- Git
- Google Chrome or Chromium for PNG table exports generated through `chromote` / `webshot2`
- Access to the World Justice Project OneDrive / SharePoint folders referenced in `src/utils/config.R`

All R package versions are managed by `renv.lock`. Restore the project library before running the pipeline:

```bash
Rscript --vanilla -e "
if (!requireNamespace('renv', quietly = TRUE)) install.packages('renv', repos = 'https://cloud.r-project.org')
renv::restore(prompt = FALSE)
"
```

### macOS Compilation Notes

If `renv::restore()` fails while compiling packages that require `gettext`, install it through Homebrew and expose the headers and library to R:

```bash
brew install gettext

mkdir -p ~/.R
cat << 'EOF' > ~/.R/Makevars
CPPFLAGS += -I/opt/homebrew/opt/gettext/include
LDFLAGS += -L/opt/homebrew/opt/gettext/lib -lintl
EOF
```

## Local Configuration

The project is not fully self-contained. It expects local OneDrive / SharePoint paths for source data and shared report assets:

- `path2EU`: EU Subnational / EU-S Data folder
- `path2DA`: Data Analytics folder

These paths are set in `src/utils/config.R` for known local usernames. Update that file before running the pipeline on a new machine or account.

The visualization worker also expects the Inter Tight font files under:

```text
{path2DA}/6. Country Reports/0. Fonts
```

## Inputs

Tracked inputs:

- `data/regions.csv`: regional metadata and population weights

Local or generated inputs that are intentionally ignored by git:

- `data/master.csv`: generated by `Rscript main.R --data`
- `data/jg_data_keepdk.csv` and `data/jg_data_nodk.csv`: generated during special-variable processing

External source data:

- `{path2EU}/eu-gpp/1. Data/3. Merge/EU_GPP_2024.dta`
- `{path2EU}/reports/eu-thematic-reports/data-viz/output/data4web_gpp.csv`

## Running the Pipeline

Run all routines from the terminal through `main.R`:

```bash
Rscript main.R [OPTIONS]
```

Available options:

| Flag | Description |
| --- | --- |
| `--data` | Load and wrangle the EU-GPP source data into `data/master.csv` |
| `--analysis` | Produce analysis tables and supporting analysis figures |
| `--viz` | Produce report-ready SVG visualizations; this sources the analysis worker internally |
| `--main_indicators` | Produce `output/tabs/main_indicators.xlsx` for the configured study countries |
| `--eu_main_indicators` | Produce EU-average main indicators as the average of weighted country averages |
| `--update-packages` | Update project packages with `renv` and refresh `renv.lock` |
| `--verbose` | Print timestamped progress messages |
| `-h`, `--help` | Show command-line help |

Recommended full run from raw data:

```bash
Rscript main.R --data --viz --main_indicators --eu_main_indicators --verbose
```

Useful targeted runs:

```bash
Rscript main.R --data --verbose
Rscript main.R --analysis --verbose
Rscript main.R --viz --verbose
Rscript main.R --main_indicators --verbose
Rscript main.R --eu_main_indicators --verbose
```

`--viz` already runs the analysis worker, so `Rscript main.R --analysis --viz` is usually redundant.

## Outputs

Generated outputs are ignored by git and written under `output/`:

- `output/tabs/csv/`: analysis CSV tables
- `output/tabs/png/`: PNG and HTML table exports and analysis figures
- `output/tabs/main_indicators.xlsx`: country-level visual indicators
- `output/tabs/eu_main_indicators.xlsx`: EU averages and country averages used to compute them
- `output/tabs/csv/eu_main_indicators.csv`: EU-average indicator table
- `output/tabs/csv/eu_main_indicators_country_averages.csv`: country-average inputs for EU averages
- `output/viz/{country}/`: report-ready SVG visualizations

`OECD-Reports/` contains report-facing Word and Excel artifacts used outside the R pipeline.

## Pipeline Logic

`main.R` is the project entry point. It parses command-line flags, loads the project configuration, and runs workers in this order when requested:

1. `src/data/worker-data.R`
2. `src/analysis/worker-analysis.R`
3. `src/viz/worker-viz.R`

The data worker loads EU-GPP data, applies special demographic and access-to-justice recodes, applies the quality-control exclusion, and writes `data/master.csv`.

The analysis worker loads `data/master.csv`, `data/regions.csv`, and justice-gap data, then runs Modules 1-5 to produce tables and analysis outputs under `output/tabs/`.

The visualization worker sources the analysis worker, registers the report fonts, loads EU comparison data from the thematic-reports pipeline, and writes SVG graphics under `output/viz/{country}/`.

The main-indicator routines convert selected visual-table outputs into workbook-ready indicator tables:

- `src/analysis/main_indicators.R` builds indicators for the configured study countries.
- `src/analysis/eu_main_indicators.R` builds weighted country averages for all countries in `data/regions.csv`, then computes EU averages as the average of those country averages.

## Quality Control

Responses from people who reported more than 25 non-trivial legal problems are excluded from justice-experience analyses by setting the affected variables to missing or zero as appropriate for the metric.

The threshold is defined in `src/data/special-vars.R`:

```r
QUALITY_CHECK_NONTRIVIAL_THRESHOLD <- 25
```

The main helper functions are `build_quality_check()`, `apply_quality_check_to_experience_vars()`, and `apply_a2j_quality_check()`.

## Contribution Notes

- Prefer running routines through `main.R`.
- Use `renv::install()` and `renv::snapshot()` when adding or updating R dependencies.
- Call functions outside `base` and the core `tidyverse` with the namespace operator, for example `haven::read_stata()`.
- Keep generated outputs out of git unless they are explicitly needed as report-facing artifacts.
